Demand Forecasting using Machine Learning

A predictive model built on 2 years of daily sales data to enhance forecast accuracy and minimize stockouts using advanced Machine Learning techniques.

Project Overview

This project focuses on analyzing 73K rows of historical sales data to build a robust demand forecasting model. Due to highly volatile sales patterns and weak seasonality, traditional time-series methods proved insufficient.

By implementing a Machine Learning approach with feature engineering—including lag variables, rolling windows, price, and discount data—the model achieved a 98% Weighted Absolute Percentage Error (WAPE), significantly outperforming traditional methods.

Project Details
  • Tools: Python, Pandas, Scikit-Learn, Machine Learning
  • Domain: Retail Analytics & Time Series
  • Focus Areas: Predictive Modeling, Feature Engineering, Data Cleaning
  • Project Type: Machine Learning & Data Analysis

Analysis Highlights

  • Data Cleaning & Optimization conducted on a dataset of 73K rows, optimizing datatypes and aggregating daily sales to prepare a clean foundation for modeling.
  • Advanced Feature Engineering implemented by creating Lag features, Rolling averages, and incorporating Price/Discount data to capture complex sales drivers.
  • Model Comparison revealed that traditional time-series forecasting performed poorly due to volatility, while the ML model successfully adapted to the patterns.
  • Achieved 98% WAPE (Weighted Absolute Percentage Error), demonstrating high reliability for business-critical inventory decisions.
  • Identified Top Sellers and analyzed monthly sales trends by product category to prioritize high-impact inventory items.
  • Inventory Planning Support enabled by accurate predictions, which directly assist in reducing stockouts and optimizing replenishment cycles.
